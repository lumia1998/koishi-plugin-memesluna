## 升级指南

### 从 v0.6.0 升级

1. **安装新版本**
   ```bash
   npm update koishi-plugin-memesluna
   ```

2. **添加新配置**（可选）
   ```yaml
   plugins:
     memesluna:
       # AI 成本控制
       aiDailyLimit: 1000
       aiWarnThreshold: 0.8
   ```

3. **重启 Koishi**
   ```bash
   koishi restart
   ```

**无需数据迁移** - 数据库结构未变化，索引自动创建。
